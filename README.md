# Burger Maker 🍔

A 3D burger cooking game built with Unity.

## About

Burger Maker is a learning project where players prepare burgers by collecting ingredients, cutting vegetables, cooking meat, assembling orders, and delivering them before time runs out.

## Features

- 3D Player Movement
- Interactive Kitchen Counters
- Pick Up & Drop System
- Ingredient Cutting
- Meat Cooking System
- Plate Assembly
- Order & Delivery System
- Scriptable Object Based Recipes
- Sound Effects
- UI & Game States

## Built With

- Unity
- C#
- Unity Input System
- Scriptable Objects
- Cinemachine
- TextMesh Pro

## Controls

| Key | Action |
|------|--------|
| WASD | Move |
| E | Interact |
| F | Alternate Interact |
